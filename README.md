### 🚀 CloudOps Copilot

Copilot técnico capaz de gerar planos de deploy, orientar boas práticas de segurança e ajudar na resolução de problemas. Deployado em AWS EC2 com Nginx e systemd.

`Python` · `FastAPI` · `OpenAI SDK` · `AWS EC2` · `Nginx`

[🔗 Repositório](https://github.com/ognistie/CloudOps-copilot)
